ArmsorPlus

为 Minecraft Paper/Purpur 服务器带来 RPG 化的装备、附魔、BOSS 战斗与饮食系统。
基于 PDC 存储的 30+ 自定义附魔，不占用原版附魔槽位。

Paper 1.21+ Java 21 零前置依赖 开源 (非商业)
下载最新版本 查看源代码

为什么选择 ArmsorPlus？

从基础到进阶，全方位提升您的 Minecraft 体验

30+ 自定义附魔

基于 PDC 存储，拖拽即用。不与原版附魔冲突，支持装备/武器/工具/弓箭四类附魔。

强化石系统

通过基础强化石随机获得各类强化石，拖拽到装备上即可提升属性，简单直观。

13 件魔法武器

每一件都拥有独特的右键技能：飞行、瞬移、隐身、箭雨、蓄力投掷等。

5 大 BOSS 挑战

急冻树、爆炎树、史莱姆王、僵尸巨人、小僵尸双胞胎 — 含元素反应机制。

食物与药品

回春散、止血绷带、酒桶、30+ 种水果，以及丰富的烹饪合成配方。

果树种植

20+ 种果树树苗：苹果、樱桃、荔枝、龙眼、椰子、菠萝等，种下即可收获。

公海世界

独立地图 + 宝藏抽奖 + 守护者挑战，可配置自动重置，一切尽在 config.yml。

玩家设置

附魔通知开关、管理员模式等，每个玩家可单独配置。

魔法球抽奖

消耗经验值兑换魔法球，右键抽取随机附魔书。寻常/稀罕/史诗/传奇 四种品质。

公海世界

独立世界地图 · 宝藏抽奖 · 守护者挑战

在 config.yml 中开启公海世界后，服务端自动加载独立地图。
玩家可在其中探索宝藏、挑战守护者，享受海洋冒险。

SpawnOpenSea: false # 是否启用
AutoResetOpenSeaMap: false # 自动重置
OpenSeaName: "OpenSea" # 世界名
MapZipName: "OpenSea.zip" # 地图包名

快速开始

  1. 下载 ArmsorPlus.jar 放入 plugins/ 目录
  2. 重启服务端
  3. 用 1 个圆石合成 高级附魔向导书，右键打开主菜单
  4. OP 玩家使用 /ArmsorPlus help 查看管理命令

指令参考

需要 ArmsorPlus.op 权限（默认 OP）

指令说明
/ArmsorPlus help查看帮助
/ArmsorPlus info插件信息
/ArmsorPlus guide获得高级附魔向导书
/ArmsorPlus give <item> [amount] [level]给予物品
/ArmsorPlus getEnchantmentLevel <enchant>查看手持物品附魔等级
/ArmsorPlus removeEnchant <enchant|all>移除手持物品附魔
/ArmsorPlus reloadmap重载公海地图

自行构建

环境要求 JDK 21+

# 构建
./gradlew build
# 产物在 build/libs/ArmsorPlus-1.0.jar
# 启动测试服务端 (Purpur 1.21.11)
./gradlew runPurpur
# 仅更新插件 jar (热重载)
./gradlew reload
